How It Works:

The Thread the Needle effect triggers when:

  1. A bubble passes through a gap between two stationary bubbles
  2. The gap width is less than 1.5x bubble diameter
  3. The bubble trajectory passes close to the gap center
  4. The bubble is actively moving toward the gap

Scoring System:

// Base score for threading const baseScore = 50; // Multipliers Tight gap (< 1.3x diameter): 2.0x Normal gap (< 1.5x diameter): 1.5x Wall bounce bonus: +0.5x per bounce // Example calculations Normal thread: 50 × 1.5 = 75 points Tight thread: 50 × 2.0 = 100 points Tight + 1 bounce: 50 × 2.5 = 125 points Tight + 2 bounces: 50 × 3.0 = 150 points
