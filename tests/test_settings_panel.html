Expected Behavior

When Settings Icon is Clicked:
  1. Settings panel appears centered on screen
  2. Game overlay darkens the background
  3. "PAUSED" text appears
  4. gameState.isPaused is set to true
  5. All game animations stop
  6. Mouse movements don't update trajectory
  7. Clicking doesn't shoot bubbles
When Settings Panel is Closed:
  1. Settings panel disappears
  2. Game overlay is removed
  3. gameState.isPaused is set to false
  4. Game resumes from where it was paused
  5. Mouse controls work again

Manual Testing Steps

  1. Open the game in a browser
  2. Start playing normally
  3. Click the settings icon (cog) in top-right
  4. Verify the game pauses and shows "PAUSED"
  5. Try moving mouse - trajectory should not update
  6. Try clicking - bubbles should not shoot
  7. Adjust music settings in the panel
  8. Click the X button or outside the panel to close
  9. Verify the game resumes normally
